OpenCode 配置修改器

先导入已有 opencode.json 或 opencode.jsonc，再用表单修改和下载。适合配置默认模型、思考额度、第三方供应商、OpenAI 兼容接口、模型上下文限制，以及 MCP、Agent、权限等高级配置。

快速开始

1. 必须先导入你的 opencode.json；2. 再修改模型、供应商和高级配置；3. 在右侧检查 JSON；4. 下载后覆盖或保存到 OpenCode 配置目录。

官方字段优先 未知字段保留 纯前端运行 适合 GitHub Pages

基础设置

这些字段会直接写入顶层配置。未填写的项目会在导出时自动省略。

第三方供应商与模型

支持 OpenAI 兼容接口、自定义 npm provider、baseURL、apiKey、模型上下文、输出限制和思考参数。apiKey 会写入 provider.options.apiKey；也可以只填写环境变量名。

高级配置

MCP、Agent、权限、格式化、LSP、命令、引用、技能、插件等复杂对象可以在这里用 JSON 片段编辑。

实时 opencode.json

导出前建议确认模型 ID、供应商 ID、baseURL 与环境变量名称。
