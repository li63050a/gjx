🌐 DNS 解析工具

输入域名后点击“解析”。数据来自 Cloudflare / Google 的 DNS-over-HTTPS（DoH），已尝试走加速代理。

说明：A=IPv4 地址，AAAA=IPv6 地址，CNAME=别名，MX=邮件服务器，TXT=文本记录，NS=域名服务器，HTTPS/SVCB=现代 TLS 连接记录（含对应 IP 与端口）。部分域名 IPv6 可能为空属正常。
